# Integridad de datos y privacidad

Cada dato que afecta una instrucción de viaje debe tener fuente, fecha, estado y método de verificación. No inferir una tarifa, parada o frecuencia. No reutilizar un competidor sin permiso/licencia.

No guardar DNI, teléfonos, dirección de hogar, historial de viaje, ubicación GPS del pasajero, rostro, voz o placa. La geolocalización de origen se solicita solo al usuario, se procesa localmente y no se envía al servidor.

Los reportes temporales se etiquetan como observaciones de pasajeros, tienen caducidad y nunca actualizan el catálogo verificado automáticamente. No mostrar una ETA ni una posición de combi sin telemetría real autorizada.
